# Strömstad Hobby

## Beskrivning
WordPress-tema för Strömstad Hobby, en fiktiv hobbybutik i Strömstad.

## Installation
1. Ladda upp temamappen till wp-content/themes/
2. Aktivera temat i wp-admin
3. Installera plugins: Yoast SEO, Contact Form 7
4. Skapa kategorierna nyheter och puffar

## Tekniker
- WordPress
- PHP
- HTML/CSS
- MySQL

## Temastruktur
- `style.css` — Temats stylesheet
- `functions.php` — Registrerar menyer, widgets, stöd för logotyp och thumbnails samt custom post type för produkter
- `header.php` — Sidhuvud med navigering
- `footer.php` — Sidfot
- `front-page.php` — Startsida med puffar och nyheter
- `page.php` — Standardsida
- `page-with-sidebar.php` — Sida med sidebar
- `single.php` — Enskilt inlägg
- `index.php` — Nyhetssida
- `archive-produkt.php` — Produktarkiv för produkstsidan

## Plugins
- Yoast SEO — sökmotoroptimering 
- Contact Form 7 — kontaktformulär
